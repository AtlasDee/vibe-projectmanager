## 2026-11-09 (10) — 去掉写死的本机路径，md5 改用自带跨平台脚本

- **问题**：PRD 评审一步原先写死了作者本机的导出工具路径，还用了两条在 PowerShell 里会被拆坏的单行命令。别人装上这个 skill 后会出错。
- **md5 改由 skill 自带的 `scripts/prd_md5.py` 计算**：只用 Python 标准库，Windows / macOS / Linux 通用。
  - 默认算整个文件；`--lark-export` 只剥掉 Lark / 飞书导出文件的固定文件头，文件头不符时报错，不猜。
  - 已用真实导出文件核对，结果与原算法一致。
- **云文档导出工具不再绑定**：先看用户在 CLAUDE.md 等处约定的工具，没有就问用户，也可以由用户手动导出。门禁记录新增「导出方式」，换了导出方式就重新冻结。
- 机械校验新增两项：skill 内不得出现本机绝对路径；提到的脚本必须存在。

## 2026-11-09 (7) — 按第三轮复核全部修改

- **PRD 版本比对（md5）**：
  - 改为写死的命令：云文档按固定参数导出，只剥掉固定的文件头，正文一字不跳；原写法会把开篇摘要高亮块当文件头跳过。
  - 冻结版留档，比对不一致时先 diff，分清是正文改动还是导出噪声。
  - 写明图片、画板的改动不在覆盖范围内。
  - 已在一份真实云文档上验证：两次导出、链接与 token 两种导出方式，正文 md5 都一致；只改摘要一个词，md5 随之改变。
- **未确认依赖**：概率记高，影响按依赖强度和是否在关键路径照实判；什么时候升级按依赖的触发条件。
- **RAID 复核分两层**：每周过一遍、到期再逐条细看。四张表加「上次复核」列，依赖状态与健康度颜色一一对应，加「受阻」状态。
- **变更评审**：升级后可裁定放行、继续修改或撤回；撤回时 PRD 回退到上一个放行版本。
- 另有十余处措辞与一致性修正，来源说明补全 6 处取舍声明。
